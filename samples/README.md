# Sample drawings

Two furniture elevation sheets (vector PDFs with a text layer, dimensions in **cm**): `GLADIOGROUP_P02_PW-ZM05_12.pdf` (cabinet elevations, one cabinet per view) and `06_A_METROPILITAN_NRF-zabudowy meblowe_widoki.pdf` (multi-view sheet with desks and cladding).
They are used by the tests (`tests/conftest.py::sample_file`) and for the demo; any other project package goes into the git-ignored `sample-data/<project>/` directory.
